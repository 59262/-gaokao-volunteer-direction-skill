# 高考志愿填报方向选择 Skill

这是一个面向大模型或 Agent 对话场景的中文高考志愿填报方向分析 Skill。它通过分步提问收集考生的省份、年份、科类或选科、位次、偏好、预算和限制条件，帮助用户理解学校、专业、城市、就业与录取安全之间的取舍。

本项目是**提示词和文档项目**，当前没有网站、后端服务、命令行程序或可执行构建产物。核心文件是 [`高考志愿填报方向选择Skill.md`](./高考志愿填报方向选择Skill.md)。

## 功能与边界

- 按固定顺序完成基础信息、偏好、预算、限制条件和优先级采集。
- 解释位次、批次、专业组、调剂、冲稳保垫和预算风险。
- 在数据充分时输出候选院校/专业组池、方向报告和一页式总结。
- 要求使用本省教育考试院、阳光高考、高校招生章程和当年招生计划进行最终核验。
- 不替用户提交志愿，不承诺录取结果，不把评分当作录取概率。

## 环境要求

- 一个支持长文本系统提示词或 Skill 的大模型对话环境。
- 如需给出具体院校建议，应具备可靠的公开信息检索能力，或由用户提供官方招生计划、招生章程和位次数据。
- 不需要安装 Python、Node.js 或数据库；当前仓库没有运行时依赖。

## 安装与运行

本项目不需要编译或安装。下载仓库后，直接在支持 Skill/系统提示词的对话环境中导入核心 Markdown 文件即可运行；运行过程发生在宿主模型中，不会在本地启动服务。

## 配置

当前版本没有仓库级配置文件、环境变量或数据库。模型平台、联网能力、日志和数据留存由宿主平台管理；不要把平台密钥写入本仓库。如果未来加入配置，先更新 `.env.example`、安全说明和审计清单。

## 使用方法

1. 打开 [`高考志愿填报方向选择Skill.md`](./高考志愿填报方向选择Skill.md)。
2. 将全文作为系统提示词、开发者提示词或 Skill 指令导入支持该格式的对话环境。
3. 按 Skill 的顺序回答问题；未知信息可写“暂无 / 不确定 / 跳过”，不得由模型擅自补全主观偏好。
4. 在正式分析前核对确认摘要，并准备本省官方数据。
5. 将输出当作讨论和筛选材料，提交志愿前逐项核验官方系统中的代码、计划、专业组、学费、校区和调剂规则。

虚构输入示例见 [`examples/sample-input.md`](./examples/sample-input.md)，完整使用说明见 [`docs/usage.md`](./docs/usage.md)。

## 数据与隐私

请不要把姓名、身份证号、准考证号、手机号、住址、账号、密码、健康记录或完整私人对话直接提交到公开仓库。分数、位次、选科、预算和志愿偏好也可能构成可识别的教育信息，应使用虚构或脱敏数据。

本项目不内置数据库，也不要求环境变量。若使用联网模型，模型访问的来源、日志和保留策略由所使用的平台决定，请按平台政策处理。

## 已知限制

- 当前版本没有自动抓取、校验或缓存招生数据的实现。
- 具体院校、专业组和规则必须以当年官方信息为准；历史数据不能替代当年计划。
- 不同省份、科类、批次和艺术/体育类规则可能不同，Skill 只能提供分析框架。
- 当前仓库没有自动化测试、构建或 lint 流程。
