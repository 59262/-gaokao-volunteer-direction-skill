# 使用说明

## 适用场景

本 Skill 适合在大模型对话中做高考志愿填报的方向梳理、风险识别和官方核验准备。它不是录取预测器，也不是自动填报工具。

## 推荐流程

1. 导入 `高考志愿填报方向选择Skill.md`。
2. 先回答基础信息，再按顺序完成志愿偏好、专业偏好、家庭预算、限制条件、个人倾向、决策优先级和已有想法。
3. 对不知道的主观问题写“暂无 / 不确定 / 跳过”；不要让模型替你推断。
4. 对公开数据优先使用本省教育考试院、阳光高考、高校招生章程、本科招生网、当年招生计划和一分一段表。
5. 在生成报告前确认信息摘要；如果院校数据不足，应接受“选校区间/匹配预案”，不要要求模型编造学校或位次。
6. 最终提交前，逐项核验院校代码、专业组代码、专业代码、招生人数、选科要求、调剂范围、学费、校区、体检和截止时间。

## 输入最小集合

- 省份和高考年份
- 科类或选科组合
- 分数与全省位次（艺术类还需专业分/综合分口径）
- 批次和批次线
- 最重要的偏好或排序
- 明确不能接受的专业、城市、费用或限制

## 输出解读

报告中的“冲、稳、保、垫”是风险分层，不是录取概率。评分只用于比较方向。任何具体学校和专业组都应标注数据年份、来源、是否官方以及待核验项。

## 隐私注意

建议使用虚构姓名和示例数据，或只提供完成分析所需的最少信息。不要上传身份证件、联系方式、家庭住址、账号凭证和完整私人对话。
